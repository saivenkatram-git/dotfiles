# My Dotfiles

My personal configuration files.

## What's Included

### Terminal & Shell

- **Ghostty** - Terminal emulator configuration
- **tmux** - Terminal multiplexer settings (`.tmux.conf`)
- **Zsh** - Shell configuration (`.zshrc`)
- **Oh My Posh** - Custom prompt theme

### Editor

- **Neovim** - Editor configuration and plugins
